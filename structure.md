Sesuai dengan hakikat Clean Architecture, maka semua komponen yang digunakan secara global akan masuk ke folder core seperti app_theme, app_images, app_spacing, dan app_size. Lalu apa saja yang masuk ke folder feature? sesuai namanya setiap fitur2 yang dimiliki aplikasi maka akan masuk ke folder feature seperti WatchList dan Authentication. Dalam folder Feature/[nama feature] terdapat lagi sub-folder yang berisikan data, domain, dan presentation. dimana folder data merupakan tempat terhubungnya entities ke database, domain merupakan model tabel database dan presentation merupakan view yang akan ditampilkan oleh aplikasi.
